深鲸守护 · 依赖投毒与风险 —— 5 条规则
 
[high] DEP-LIFECYCLE
依赖带 install 生命周期脚本（投毒主要载体）
依据：npm Docs — scripts: preinstall/install/postinstall；近年来 npm 投毒事件（event-stream、ua-parser-js、node-ipc、colors/faker）均通过生命周期脚本执行任意代码
 
[medium] DEP-NO-LOCKFILE
仓库没有 lockfile（依赖树不确定）
依据：npm Docs — package-lock.json：锁定依赖树，保证不同环境安装出相同结果
 
[medium] DEP-WILDCARD
依赖版本过宽（* 或 latest）
依据：npm Docs — semver: `*` 匹配任意版本；`latest` 表示 dist-tag 最新
 
[medium] DEP-INSECURE-SOURCE
依赖来自非 registry 来源（git / http / 本地路径）
依据：npm Docs — package.json 依赖协议：git+ / http:// / file: / link:；npm Docs — 供应链安全建议
 
[low] DEP-RANGE-WIDE
依赖使用 >= 或 > 开放区间
依据：npm Docs — semver ranges：`>=x.y.z` 无上界，可能跨越 breaking change

· 仓库没有 lockfile（依赖树不确定）
位置 package-lock.json
证据 以下任一均不存在：package-lock.json / pnpm-lock.yaml / yarn.lock / bun.lockb
依据 npm Docs — package-lock.json：锁定依赖树，保证不同环境安装出相同结果
建议 没有 lockfile 时，`npm install` 每次可能装到不同版本 —— 今天构建通过、明天因为某个间接依赖发新版就挂了，或者悄悄引入了被投毒的版本。提交 lockfile 到版本控制。

仓库没有 lockfile（依赖树不确定）
npm Docs — package-lock.json：锁定依赖树，保证不同环境安装出相同结果
 package-lock.json
以下任一均不存在：package-lock.json / pnpm-lock.yaml / yarn.lock / bun.lockb
 没有 lockfile 时，`npm install` 每次可能装到不同版本 —— 今天构建通过、明天因为某个间接依赖发新版就挂了，或者悄悄引入了被投毒的版本。提交 lockfile 到版本控制。

npm Docs — semver: `*` 匹配任意版本；`latest` 表示 dist-tag 最新

 `*` / `latest` 等于把「装到哪个版本」交给上游决定 —— 上游发新版本（或被投毒）你立刻受影响，且无法复现。改成明确的 semver 范围或精确版本。
